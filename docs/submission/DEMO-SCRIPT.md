# Demo Video Script

## Recording contract

| Field | Value |
| --- | --- |
| Target runtime | **~80 seconds** |
| Acceptable range | **75–90 seconds** |
| Absolute maximum | **under 3 minutes** |
| Audio | English voiceover and interface audio |
| Music | none preferred; if used, only material the entrant owns and may legally use |
| Recording URL | `https://brenych-agent-interface.pages.dev/` |

Do not simulate an agent interaction. Record whatever the host actually does.

## Recording paths

### Path A — ChatGPT Site Tools (preferred if access is available)

Record in the ChatGPT desktop app's built-in browser. This is the most
compelling footage, because the page visibly recomposes under agent control
while the human watches. Use the prompts in
[`TESTING-INSTRUCTIONS.md`](TESTING-INSTRUCTIONS.md).

### Path B — Chrome WebMCP (certified fallback)

Record in Chrome 152+ with `chrome://flags/#enable-webmcp-testing` enabled. This
is the host the production release was certified on, so this path is always
available and always truthful.

Either path satisfies the Challenge, which accepts both hosts.

## Do not

- Do not spend time navigating GitHub.
- Do not show white navigation or loading flashes.
- Do not use copyrighted music.
- Do not claim ChatGPT Site Tools certification unless that run actually happened.
- Do not fake or composite an agent interaction.
